## 取（吸收了什么，落到哪）

- `#D4AF37` 实色金、`#1A1A1A` 深底、`#F5F0E8` 奶油白 → `deco-ceremony`。
- 中轴对称、阶梯／放射几何、1–2px 双线框 → Layout、Elevation 与 Shapes。
- Playfair Display／Cormorant Garamond 和 500ms 缓慢过渡 → Typography 与 tokens.css。

## 弃（明确不吸收，为什么）

- 0.2–0.3em 的宽字距小标题 → 中文与标签可读性差，收敛到展示 0.08em、标签 0.04em。
- 渐变金字、金色光晕 → 违反本库反模板规则，也削弱建筑般的实线结构。
- 具体酒店、珠宝品牌资产与文案语气 → 不属于可复用风格。
