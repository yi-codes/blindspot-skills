## 取（吸收了什么，落到哪）

### 1. 纯黑纯白是可以用的，但要付代价

它用 `#000000` 做 primary 和 ink，`#ffffff` 做 canvas。我一直主张"不用纯黑纯白"，这份样本是反例。

但它付了三个代价：**全站只有一张连续的白纸**（没有任何表面交替）、**形状语言绝对统一**（所有交互元素都是 pill）、**全页只有一处深浅反转**（最高价档）。

→ **已落到** `principles.md`：纯黑纯白的风险不在色值本身，在"没有别的东西撑着"。三件撑住它的东西缺一不可。
→ **未改** `swiss-grid` 的 `#111111` / `#FFFFFF`。因为 swiss 的表面层次比它多（canvas / surface / surface-alt 三档），用纯黑会打架。

### 2. 唯一一次反转

整个系统是平的白，只有最高价档 `{component.pricing-card-dark}` 是深色。稀缺性本身就是注意力。

→ **已落到** `principles.md` 第 2 节（一个画面只有一个主角）的补充例证。
→ **待用**：以后做定价页类的东西，可以直接用这个手法——把想强调的那一个做成全页唯一的反色块，比加十个徽章有效。

### 3. 圆角必二选一，没有中间派

按钮、输入框、搜索框、终端装的药丸、甚至终端窗口的红黄绿灯点，**全是 `{rounded.full}`**。卡片用 `{rounded.lg}` 12px。

→ 强化了 `swiss-grid` 已有的规则："要么统一 2px，要么统一 pill"。
→ **新增一条判断**：Ollama 的 pill 之所以成立，是因为它的标题字体是 SF Pro Rounded——**圆形的字配圆形的按钮，形状语言自洽**。字体方正却全用 pill，就会廉价。

### 4. 文档即设计

首页的签名元素是一个 `curl ... | sh` 的安装命令，做成药丸状，直接放在大标题下面。

→ **待吸收**：`terminal-mono` 目前把代码块当作"内容的一部分"。可以学它——**把最关键的一条命令做成视觉焦点**，而不是埋在正文里。

### 5. mute 用 #a3a3a3

它的灰阶是 `#525252` charcoal / `#737373` body / `#a3a3a3` mute。最后一档跟我原来的 `swiss-grid` ink-faint 完全一样。

→ **张力记录**：我按 WCAG 3.0 把它改到了 `#8F8F8F`（3.23:1），因为 `#a3a3a3` 在白底上只有 2.52:1。
→ 结论：**WCAG 是底线，不是审美标准**。行业惯例（Tailwind neutral-400 就是这个值）和可访问性在这里冲突。我选择保守——占位符和禁用态在"能看清但明显很弱"之间，`#8F8F8F` 更安全。这个取舍写在 `principles.md`。

## 弃（明确不吸收，为什么）

- **`#000000` / `#ffffff` 本身**：见上，需要三个前提条件才成立，不适合作为通用默认。
- **SF Pro Rounded**：苹果系统字体，跨平台不可用（安卓/Windows 会退化）。它的圆润感是风格核心，退化后就不是这个风格了。
- **羊驼吉祥物**：品牌资产，且"唯一装饰物"的用法高度依赖"其它地方什么都没有"。
- **终端红黄绿灯点**：macOS 特有视觉习惯，放到技术文档里会变成"假装是截图"。
- **36px 居中大标题**：文档型首页专用。阅读型内容居中排版会破坏 34em 的阅读节奏。

## 待观察

- "一张连续的白纸"（零表面交替）在长页面上会不会失去节奏感？它的页面都很短。
- 全 pill 的圆角 + 等宽字体能不能共存？Ollama 没用等宽做标题，我不知道答案。
- 它的颜色 token 有 21 个，比我的 10 个多一倍，但视觉效果更简单。**token 数量与视觉复杂度无关**——这一点值得记：拆得细是为了表达精确，不是为了用得更多。
