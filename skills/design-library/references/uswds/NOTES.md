# U.S. Web Design System

## 来源

- 仓库：[`uswds/uswds`](https://github.com/uswds/uswds)
- 许可：GitHub 元数据为 `NOASSERTION`；使用代码前需逐文件核验
- 角色：公共服务、移动优先、无障碍表单
- 落点：`styles/civic/`

## 取

- 公共服务先在移动端完成关键任务，再扩展桌面。
- 表单位置、标签、帮助文字和错误说明必须可预测。
- 无障碍不是单独页面，而是所有组件的默认状态。
- 页面目标应从用户任务命名，而不是组织内部结构命名。

## 弃

- 未确认许可边界前不复制代码和资产。
- 不使用美国政府品牌元素。
- 不把政务页面的特定视觉当作所有公共服务的唯一答案。
