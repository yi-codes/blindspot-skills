# Vercel Geist

## 来源

- 仓库：[`vercel/geist-font`](https://github.com/vercel/geist-font)
- 许可：OFL-1.1
- 角色：开发者产品的字体与代码排版
- 落点：`styles/developer-docs/`

## 取

- 正文字体与代码字体承担不同职责，不要求全文等宽。
- 代码字号、行高和代码块密度需要稳定，不随页面标题一起变化。
- 字体作为开放资产可以分发时，仍需保留许可和 fallback。

## 弃

- 只有一个字体仓库，不能据此推导完整页面风格。
- 不复制 Vercel 品牌几何、黑底营销页或产品文案。

## 待观察

- 中文字体回退在不同操作系统下的行高差异。
- 代码字体与中文混排时的基线和标点对齐。
