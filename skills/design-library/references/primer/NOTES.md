# GitHub Primer

## 来源

- 仓库：[`primer/design`](https://github.com/primer/design)
- 许可：MIT
- 角色：开发者产品、代码与说明关系、工作流状态
- 落点：`styles/developer-docs/`

## 取

- 文档导航、正文与参考内容需要共享同一套语义，不把“概念”和“API”做成两个视觉世界。
- 代码块需要文件名、语言、复制和版本上下文，不能只是一块深色背景。
- 状态与操作靠近发生位置，减少跨页跳转。
- 焦点状态和键盘操作是产品体验的一部分，不是补充项。

## 弃

- GitHub 品牌色、Octocat、产品页面版式不作为风格资产。
- 不复制 GitHub 的具体组件实现；只吸收可写成规则的结构与状态。

## 待观察

- 大型多版本文档的版本切换和弃用提示需要单独压力测试。
- 移动端代码块横向滚动与复制反馈尚未形成统一组件。
