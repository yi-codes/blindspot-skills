# inbox/ —— 原料入口

看到喜欢的东西，先扔这儿。不要当场判断它值不值得吸收。

## 怎么扔

文件名格式：`YYYY-MM-DD-一句话描述.扩展名`

```
inbox/
├── 2026-11-15-某产品定价页那个反色块.jpg
├── 2026-11-16-linear-官网的灰色层级.png
└── 2026-11-18-muji-包装上的字距.md
```

- **截图**：直接放进来，`.png` / `.jpg` 都行
- **链接**：建个 `.md`，里面就一行 URL 加一句"我觉得哪里好"
- **随手记**：`.md`，半句话也行

一句话描述写成"我为什么觉得它好"，不是"它是什么"。一年后你只会需要前者。

## 然后呢

Agent 定期过一遍 inbox，做三件事：

1. **能提炼的** → 拆成能变成数值的东西，写进 `references/<name>/NOTES.md` 的"取"，或者直接落到 `styles/` 的某个 token
2. **只是氛围的** → 留在 references 里当灵感，标注"不可 token 化"
3. **判断不了的** → 保留，不删。积压本身就是信号——攒到十个都指向同一个方向，那就是该开新风格了

处理完的文件移到 `references/` 对应目录，或者删掉（原料没有留存价值，提炼结果才有）。

## 三条纪律

1. **扔的时候不筛选**。筛选发生在提炼阶段，不是在收藏阶段。收藏时犹豫，你就什么都不会收集。
2. **不追求清空 inbox**。它是漏斗不是待办清单。常年堆着二十个没处理的截图，完全正常。
3. **不为了收而收**。判断标准是"我看到它的时候有没有想要模仿的冲动"，不是"它设计得好不好"。
