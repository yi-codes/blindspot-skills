# 设计库的策展规则

“全部保留”不等于“全部平铺”。每个风格必须说明自己对什么页面负责，以及它与已有风格的关系。

## 三层

| 层级 | 判断 | 默认推荐 |
|---|---|---|
| `core` | 必须为一种真实页面职责违反既有硬约束 | 是 |
| `variant` | 是某个核心风格的明暗、材料、密度或表达分支 | 否 |
| `technique` | 是可复用的动效、材质或组件技法 | 否 |

## 入库门槛

至少满足两项：

1. 有一组可执行 token。
2. 有一个能解释层级的结构骨架。
3. 有可验证的交互与状态。
4. 有来源、许可和“弃”的判断。

只有形容词、品牌截图或单一配色，不构成风格。

## 开源来源

许可与边界见 [`../references/SOURCES.md`](../references/SOURCES.md)。使用规则：

- 只吸收能落实为 token 或硬规则的内容。
- 不复制品牌标识、授权字体和产品文案。
- `NOASSERTION` 来源在逐文件核验前只作行为参考。
- 每个来源必须在 `references/<slug>/NOTES.md` 记录取、弃、待观察。
