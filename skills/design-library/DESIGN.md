# Design Library Catalog

## Overview

目录本身是一张**风格标本台账**。它服务的是工作，不是展示：用户在左侧缩小范围，在中间比较风格，在右侧看真实渲染并拿走接入代码。

视觉语言采用“纸上索引”而不是“圆角 SaaS 卡片”。层级由色阶、连续横线和留白建立；唯一强调色是深青色，只用于当前选择、链接和主操作。预览区域允许呈现被选风格自己的视觉世界，因此外壳与样张之间必须有清楚的边界。

## Colors

- `canvas`：冷灰纸，承载应用背景
- `panel`：稍亮的纸面，承载固定栏与详情
- `ink`：近黑墨，正文与标题
- `muted`：次级文字
- `faint`：占位与最低层级信息
- `rule`：发丝分隔线
- `accent`：唯一强调色，用于当前项和主按钮
- `accent-soft`：当前项与焦点辅助底
- `danger`：比较数量超限等错误

## Typography

标题和界面统一使用系统无衬线。正文 15px 起，长说明 16px。字号阶不是流体；应用在不同窗口大小下保持相同层级。代码、slug 和快捷键使用等宽字体。

## Layout

桌面是三栏：

1. 顶部 64px：品牌、全局搜索、构建状态
2. 左侧 208px：筛选
3. 中栏弹性：任务推荐与风格台账
4. 右侧 380 至 460px：当前风格的真实预览与详情

低于 70rem 时隐藏左栏并以顶部筛选抽屉替代；低于 52rem 时变成单列，详情跟随所选行出现。

## Elevation & Depth

不使用悬空卡片和通用阴影。层级主要由表面色差与 1px 分隔线建立。只有比较对话框允许一层带偏移的阴影，用于与底层工作台分离。

## Shapes

应用外壳圆角 8px，控件圆角 5px，状态标签圆角 3px。风格样张内部的圆角由所选风格决定，不继承目录外壳。

## Components

- 筛选：原生 checkbox 或按钮组，状态同时用文字和视觉表达
- 风格行：名称、用途、职守、明暗、密度、比较开关
- 推荐输入：描述任务，回车执行
- 预览：`iframe` 加载真实 `tokens.css` 渲染
- 详情：cues、avoid、Known Gaps、接入代码
- 比较：最多三个风格，并排、同内容

## Do's and Don'ts

### Do

- 让风格名称和用途先于装饰出现
- 让当前选择在左侧导航、中栏行和右栏详情中保持一致
- 用真实 token 渲染预览
- 复制时给出可执行片段

### Don't

- 不要用彩色卡片墙承载目录
- 不要用装饰性图标实心色块
- 不要把风格内部颜色泄露到应用外壳
- 不要让比较模式承载三个以上风格

## Chinese Typography

正文行高 1.7。界面密集区 1.5。中英文之间留四分之一个空格。标签保持原样大小写，不通过大写和字距伪装层级。正文与界面复制最多两档字重。

## When to Use

用于设计库目录自身。具体页面产物仍从 `styles/` 中选择一种风格。

## Iteration Guide

目录结构可以演进，但必须继续服务三个动作：缩小范围、比较真实渲染、拿走实现。

## Known Gaps

当前预览使用统一内容骨架，能比较基础排版和组件，不替代每个风格的完整产品场景。深度样张仍由 `showcase/` 和风格专项预览补充。
