Quiet Dark · 组件实测

左右两边是同一段 HTML，只有最外层 class 不同（ds-quiet-dark / ds-quiet-light）。所有尺寸、圆角、字重、动效来自同一组结构令牌，只有颜色分两套。

这张页是为了验证 tokens.css 里新补的四类东西真的能用：表单五个状态、动效档位、 图标规格、以及一批 app 外壳组件（导航项 / 菜单 / 对话框 / 轻提示 / 分段控件 / 键帽 / 头像）。 showcase/codex.html 那三屏是"成品长什么样"，这一页是"零件能不能拼上"。
