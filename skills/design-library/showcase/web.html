把复杂的事
说清楚

王 一·2026 年 11 月 16 日·12 分钟

好的排版不负责让人惊艳，它负责让人读下去。当一段话值得被认真读完的时候，界面应该退到后面去，只留下纸、墨，和恰到好处的空白。

行高从 1.5 加到 1.85，字数从每行 60 收到 34，同样的文字会产生完全不同的阅读速度。慢下来，这件事是设计出来的，不是读者自己决定的。

留白是一种语气

中文是满方块。拉丁字母因为字形收窄，行距紧一点反而精神；汉字每一格都填满，行距一紧就闷成一堵墙。这不是审美偏好，是几何问题。

排版不是装饰，是把作者的呼吸标出来。

所以这套风格里的数字都是定死的：正文 17px、行高 1.85、宽度 34 个汉字、圆角 0、阴影 0。改任何一个，它就不再是这个风格。

quickstart

从零到第一条同步，大约 8 分钟。

1. 安装

用官方安装脚本，会自动检测平台并校验签名：

curl -fsSL https://get.gridbase.dev | sh
gridbase --version   # v2.4.0

2. 连接数据源

取一个 API key，写进配置文件：

// gridbase.config.ts
export default {
  source: "postgres",
  url: process.env.DATABASE_URL,
  sync: { mode: "incremental", interval: 60 },
}
note incremental 模式需要表上有 updated_at 或递增主键。

3. 跑第一次同步

gridbase sync --dry-run
→ scanning 12 tables…
✓ 12 tables, 48,201 rows ready
→ estimated 1.2s
stable breaking in 3.0
