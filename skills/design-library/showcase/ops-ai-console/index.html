三张运维 AI 控制台样张

日常分诊、事故响应和 Agent 执行共用同一套证据逻辑，但界面密度、时间和安全边界各自不同。

三张都是可运行样张。所有指标、服务名与命令均为示例，不对应真实系统。点击标题进入完整页面。

  1. 日常告警分诊

    从当前信号进入证据，再把 AI 建议限制在右侧待批准区。适合值班台和交接。

    Signal Console

  2. 重大事故响应

    用连续时间线恢复现场，事实、假设、动作和验证分开记录，接班者不读聊天也能接手。

    Incident Room

  3. Agent 执行审批与回放

    把计划摘要、命令、文件、验证和待批准动作串起来，回放运行过程而不暴露隐藏推理。

    Liquid Glass

实现规则来自 Design Library 的 signal-console、incident-room 与 liquid-glass；样张数据仅用于界面比较。
