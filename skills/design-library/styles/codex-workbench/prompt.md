# Codex Workbench · 生图 Prompt 模板

## 主模板

```text
暖灰纸面工作台, 低对比自然光, 单列信息布局, 细发丝线与宽留白,
系统无衬线排版, 少量低饱和绿色标注, 安静克制的桌面工作空间
```

## 中文说明

画面重点是连续阅读和清楚的状态，不是科技感。绿色只标记当前、成功和确认。避免机器人插画、发光终端、深色霓虹和密集仪表盘。

## 负向词

```text
neon terminal, robot mascot, purple gradient, glass card pile,
dark cyberpunk, fake code rain, excessive badges
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 16:10 |
| 光线 | 午后柔和自然光 |
| 色温 | 暖中性 |
| 后期 | 低饱和、清楚材质 |
| 禁忌 | 发光、机器人吉祥物、过度卡片化 |
