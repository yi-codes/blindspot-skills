# Riso Zine｜孔版独立志 · 生图 Prompt 模板

## 主模板（可直接用）

```
[主体／粗纸墨粒], [平光／无投影], [不对称拼贴／专色叠印], [荧光粉与蓝／纸白]
```

四段式，总共不超过 8 个形容词。只生成图形和画面，不生成文字；真实标题由 HTML 或排版工具添加。

## 中文说明

- 限制为两种专色，交叉处自然形成深色叠印。
- 允许 1–3px 的视觉错位和可见纸纹，不要模糊、发光或照片级立体渲染。

## 变体

**活动海报主体**
```
[演出主体／剪纸边缘], [均匀平光], [偏心构图／双色叠印], [粉蓝专色／粗纸纹]
```

**独立刊物插图**
```
[叙事主体／丝网墨粒], [无方向平光], [局部出血／错位], [两种专色／自然第三色]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
文字、字母、Logo、紫蓝渐变、玻璃、金属、3D、柔光投影、照片磨皮、四色以上
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 海报 4:5；插图 3:2 |
| 光线 | 平光，无投影 |
| 色温 | 纸色略暖，墨色保持原色 |
| 后期 | 颗粒、错位、multiply 叠印 |
| 禁忌 | 文字、渐变、立体高光 |
