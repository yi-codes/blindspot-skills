# Pixel Arcade｜像素街机 · 生图 Prompt 模板

## 主模板（可直接用）

```
[游戏主体／像素 sprite], [无投影平光], [正交网格／单一主体], [受限蓝黄灰／硬边]
```

四段式，总共不超过 8 个形容词。使用有限色板与统一像素密度，不生成文字、分数或 UI。

## 中文说明

- 轮廓由清晰像素块组成，不要先画高清图再简单打马赛克。
- 同一画面统一 16／32px sprite 尺度，禁止混用不同像素密度。

## 变体

**游戏主视觉**
```
[街机场景／16-bit 像素], [无方向平光], [横向关卡／主体明确], [蓝黄灰／有限色板]
```

**成就徽章**
```
[奖励物／像素图标], [无投影], [居中对称／整数像素], [黄色主体／墨色描边]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
文字、数字、Logo、抗锯齿、模糊、渐变、3D、高清写实、圆角 UI、不同像素尺寸
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 场景 16:9；sprite 1:1 |
| 光线 | 平光，无投影 |
| 色温 | 中性 |
| 后期 | 最近邻放大、pixelated |
| 禁忌 | 抗锯齿、文字、柔光、渐变 |
