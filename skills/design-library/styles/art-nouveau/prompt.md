# Art Nouveau｜新艺术曲线 · 生图 Prompt 模板

## 主模板（可直接用）

```
[植物藤蔓与花苞的平涂插画], [均匀平面光 / 无景深], [非对称垂直延展 / 拱形画框 / 鞭状曲线沿边生长], [奶油纸 #F5EFE0 + 深绿 #2D5016 + 1px 烫金 #C9A227 / 酒红 #8B2252 印章级点缀]
```

四段式：主体 → 光线 → 构图 → 色彩后期。每段最多两个词，总形容词不超过 8 个；只描述物件、位置与色值，不描述情绪。画面里不要生成文字，标题、按钮与章节标记由 HTML/CSS 排版。

## 中文说明

- 主体只取植物与装饰语汇：藤蔓、花苞、鸢尾、百合、拱窗、平涂海报式剪影；不要真人特写、电子产品、城市街景、3D 拟物与几何拼贴。
- 背景用奶油纸 `#F5EFE0` 打底，卡片用软象牙 `#FAF7EF`；两层都是偏黄米色，不用纯白、不用深色底。
- 深绿 `#2D5016` 是最大面积的墨色；烫金 `#C9A227` 只走 1px 线与边框，面积 ≤5%，不铺底、不写小字；酒红 `#8B2252` 只做一枚印章级强调。
- 所有容器是拱形或鞭状曲线：上两角 999px、下两角 8px 的拱框；60% 40% 55% 45% 的不对称圆角。不要直角、方框、胶囊堆叠与三等分网格。
- 构图走非对称垂直延展：主体偏轴、视线沿一条 S 形藤蔓移动，空白也是画框的一部分；不要居中对称、不要满版堆装饰。
- 光线是平版印刷的平面光，左上单一方向；金线只在拱框上沿暗示反射。不要玻璃模糊、霓虹发光、硬边投影、渐变与紫蓝色相。

## 变体

**拱窗植物主视觉**
```
[鸢尾与藤蔓沿拱窗生长 / 平涂剪影], [均匀平面光 / 无景深], [非对称垂直构图 / 上圆下方拱框 / 金线勾边], [#F5EFE0 纸底 + #2D5016 深绿 + 1px #C9A227 金线]
```

**章节分隔纹样**
```
[一条鞭状曲线与两三片叶], [平面光 / 无阴影], [横向贯穿 / 波形振幅 8px 波长 120px / 两端留奶油纸], [#C9A227 金线 + #4A7C3F 藤蔓 / 无文字]
```

**氛围背景**
```
[奶油纸底上的藤蔓角饰与五瓣花], [平面光 / 无渐变], [装饰只待角落 / 中部留大片空白给正文], [#F5EFE0 + #FAF7EF + 少量 #8B2252 / 每屏花朵不超过三处]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
文字、Logo、水印、真实画作与车站海报、商标字标、直角方框、三等分网格、紫藤色、亮绿、霓虹、高饱和、纯白背景、黑底、紫蓝渐变、紫粉渐变、玻璃模糊、发光、0 模糊硬影、弹簧动效、几何图标、彩色摄影、3D 拟物、景深、HDR
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 主视觉 3:4 或 4:5（海报比例）；章节图 21:9；氛围背景 16:9 |
| 光线 | 均匀平面光，左上单一方向；只在金线上沿留一道反射，不投影 |
| 色温 | 奶油纸打底；深绿负责结构，烫金负责边界，酒红只给一枚印章 |
| 后期 | 平涂无渐变；1px 金线勾边；纸色两层留呼吸；不加入做旧噪点与破损纹理 |
| 禁忌 | 文字、商标、直角、几何拼贴、紫藤/亮绿/霓虹、纯白、黑底、渐变、发光、硬影、彩色摄影 |
