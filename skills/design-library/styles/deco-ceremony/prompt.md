# Deco Ceremony｜装饰艺术典礼 · 生图 Prompt 模板

## 主模板（可直接用）

```
[建筑／黄铜与漆器], [柔和壁灯], [中轴对称／阶梯几何], [深炭与实色金]
```

四段式，总共不超过 8 个形容词。画面只生成材质、空间和几何装饰，不生成文字或金属渐变字。

## 中文说明

- 对称、阶梯、放射和双线框是主要结构；金色是实色材质而非发光特效。
- 保留深炭与奶油白的安静区域，不要把所有表面都铺成金色。

## 变体

**精品酒店**
```
[酒店大厅／漆器黄铜], [柔和壁灯], [严格中轴／对称柱列], [深炭奶油白／实色金]
```

**典礼主视觉**
```
[舞台与几何桂冠], [窄幅顶光], [放射构图／阶梯边框], [深炭底／克制金色]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
文字、字母、Logo、渐变金字、霓虹、彩色光斑、圆角卡片、可爱插画、廉价金色闪光
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 主视觉 16:9；邀请页 4:5 |
| 光线 | 柔和壁灯或窄幅顶光 |
| 色温 | 暖金但保留深炭中性色 |
| 后期 | 低光雾、清晰几何边缘 |
| 禁忌 | 文字、发光、渐变、过多金色 |
