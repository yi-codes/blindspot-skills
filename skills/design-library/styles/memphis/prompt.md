# Memphis｜孟菲斯海报 · 生图 Prompt 模板

## 主模板（可直接用）

```
[平涂几何主体：塑料贴面色块 / 圆形 / 三角 / 波浪线], [无柔光、硬边、左上光源], [对角错落构图、角落斜纹与圆点、正文区留纯奶白], [玫红 #FF5C8A + 柠檬黄 #FFD23F + 薄荷 #3BCEAC + 靛蓝 #5B5BD6，墨黑 #111111 勾边与无模糊硬影]
```

四段式：主体 → 光线 → 构图 → 色彩后期。只描述物件、位置与色值，不描述情绪；总形容词不超过 8 个。画面里不要生成文字，标题由 HTML 排版。

## 中文说明

- 主体必须是明确的可辨认形状：方块、正圆、三角、波浪线，至少两种并置；不要真人正脸、动物、家具实物。
- 背景奶白 `#FFF8EC`，四色撞色同时出现但不平均用力：玫红做一处主块，黄与薄荷做次级块，靛蓝只做斜纹或细条。
- 每个形状 3px 墨黑 `#111111` 勾边，投影写成 6px 6px 0 的硬影，边缘清晰、无模糊、无发光、无玻璃高光。
- 斜纹用 45°、5px 实线 / 6px 间隔；圆点用 3px 圆 / 14px 网格；两者合计面积不超过画面 20%，且不压在预留给文字的纯色区域。
- 平涂塑料贴面质感：颜色均匀、无渐变、无照片纹理、无景深；年代感来自图案词汇与撞色，不来自颗粒滤镜。
- 禁止任何品牌商标、Memphis Group 标志、Carlton 书架轮廓、品牌吉祥物；字体也不写进画面。

## 变体

**海报 / 活动主视觉**
```
[三角 + 圆形 + 波浪线拼贴], [奶白底 / 左上硬光 / 无模糊], [对角错落 / 图案只占两角 / 中部留出纯色文字区], [玫红 + 柠檬黄 + 薄荷 + 靛蓝 / 墨黑 3px 勾边 / 6px 硬影]
```

**图标与贴纸**
```
[单一圆或方轮廓], [奶白底 / 平涂 / 无渐变], [居中 / 24px 网格对齐], [靛蓝 #5B5BD6 单色 / 3px 墨黑描边 / 3px 硬影]
```

**氛围背景**
```
[45° 靛蓝斜纹与薄荷圆点], [奶白底 / 无柔光], [分置两角 / 面积 20% / 中部纯色], [四色撞色但图案不压文字 / 无模糊无景深]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
文字、Logo、水印、Memphis Group 标志、Carlton 书架、品牌吉祥物、真人正脸、动物、照片纹理、渐变字、紫蓝渐变、紫粉渐变、玻璃高光、模糊阴影、居中发光、破损纸纹、像素字、景深、HDR、三等分对称排版
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 主视觉 4:3 或 16:9；贴纸 1:1；氛围背景 16:9 |
| 光线 | 左上单一硬光，投影固定向右下 6px 6px 0，无柔光、无环境光 |
| 色温 | 暖奶白打底，四色撞色高饱和但每屏只一个主色块；墨黑负责勾边 |
| 后期 | 平涂无渐变、无景深、无颗粒；边缘保持刀切般清晰 |
| 禁忌 | 文字、商标、模糊影、渐变字、图案压正文、对称三等分 |
