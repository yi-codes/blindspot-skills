# Signal Console · 生图 Prompt 模板

## 主模板

```text
深色运维工作台, 冷灰蓝金属表面, 一盏顶部冷白工作灯,
高密度证据布局, 清楚的时间线与指标, 低饱和蓝色信号, 无霓虹无发光
```

## 中文说明

画面要像真实值班台，重点是证据与动作相邻。颜色只承担状态，不使用科幻 HUD。拓扑与图表必须有真实标注。

## 负向词

```text
cyberpunk HUD, neon glow, purple-blue gradient, holographic screens,
floating dashboards, sci-fi cockpit, fake code rain
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 16:10 |
| 光线 | 顶部冷白工作灯 |
| 色温 | 冷中性 |
| 后期 | 清楚、低饱和、无辉光 |
| 禁忌 | 霓虹、镭射、悬浮 HUD |
