# 桌面窗口｜OS Desktop · 生图 Prompt 模板

## 主模板（可直接用）

```
[32×32 像素方块图标与灰色窗口面板], [左上单一平面光 / 无景深], [青绿墙纸上的层叠矩形窗口 / 2px 双色刻边], [#008080 青绿 + #C0C0C0 系统灰 + #000080 标题蓝 / 无圆角无柔影]
```

四段式：主体 → 光线 → 构图 → 色彩后期。每段最多两个词，总形容词不超过 8 个；只描述物件、位置与色值，不描述情绪。画面里不要生成文字，标题、按钮、任务栏与文件标签由 HTML/CSS 排版。

## 中文说明

- 主体只取 GUI 语汇：矩形窗口、标题栏三枚方块控件、32×32 图标网格、凹陷输入框、列表视图与底部任务栏；不要真人、3D 拟物、城市街景、自然风景与漫画分镜。
- 墙纸用青绿 `#008080` 实色，窗口内容用暖纸白 `#F4F2EA`，按钮面 `#DFDFDF`，任务栏 `#C0C0C0`；两层灰都偏暖，不用纯白、不用深色底。
- 标题蓝 `#000080` 到 `#0A5FA8` 的 90° 渐变只出现在活动窗口标题栏；非活动窗口标题栏用 `#808080` 灰。其余所有部件一律实色。
- 边界是 2px 外双线与 1px 内双线：上左白、下右黑，按下的瞬间明暗对调；不要圆角、pill、玻璃模糊、高斯发光与彩色渐变背景。
- 图标是 32×32 直线方块画，1px 墨线、无抗锯齿、无柔化；选中只换深蓝底与纸色字，不加光晕。
- 构图是像素级对齐的固定网格，元素吸附到 4px 基数；窗口可层叠但边缘必须水平垂直，不做斜切、不做透视。

## 变体

**桌面主视觉**
```
[32×32 文件夹与显示器图标 / 灰白窗口面板], [左上平面光 / 无景深], [青绿墙纸上两扇层叠窗口 / 2px 双色刻边 / 底部任务栏], [#008080 青绿 + #F4F2EA 纸白 + #000080 标题蓝]
```

**窗口控件特写**
```
[16×16 最小化最大化关闭方块 / 凹陷输入框], [左上受光的 1px 白线 / 无模糊], [标题栏右端横排 / 4px 间隙 / 直角矩形], [#DFDFDF 按钮面 + #808080 阴影线 + #000080 选中蓝]
```

**列表视图纹理**
```
[三格等宽矩形列表面板 / 32px 线稿图标], [均匀平面光 / 无投影], [4px 间隙的紧密网格 / 左上图标下方标签], [#F4F2EA + #C0C0C0 + 1px #000000 墨线]
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 桌面主视觉 16:9 或 4:3；控件特写 3:1；纹理 1:1 平铺 |
| 光线 | 左上单一方向平面光；只在 1px 上沿白线暗示反射，右下收 1px 黑线 |
| 色温 | 青绿墙纸打底；灰面板承担结构，深蓝只给标题栏与选中态 |
| 后期 | 无渐变后期（标题栏除外）；边缘 2px 硬刻线，窗口右下 2px 无模糊硬投影 |
| 禁忌 | 文字、商标、圆角、柔影、玻璃、霓虹、纯白大面积、黑底大面积、斜切透视、摄影与 3D |
