# Incident Room · 生图 Prompt 模板

## 主模板

```text
暖黑石墨事故响应台, 低亮桌面工作灯, 连续事件时间线, 纸质证据与终端并列,
琥珀色当前步骤, 克制红色风险, 可审计的现场记录
```

## 中文说明

现场感来自连续记录和证据，不来自警报特效。琥珀色标记当前步骤，红色只标记危险，绿色只在验证通过后出现。

## 负向词

```text
alarm lights, red flashing, cyberpunk control room, neon console,
purple gradient, sci-fi hologram, dramatic sparks
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 16:10 |
| 光线 | 低亮暖白工作灯 |
| 色温 | 暖中性 |
| 后期 | 低亮但可读，清楚层次 |
| 禁忌 | 警灯、红色泛光、戏剧化火花 |
