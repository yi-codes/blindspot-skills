# Gallery Wall｜展陈画廊 · 生图 Prompt 模板

## 主模板（可直接用）

```
[艺术主体／材质], [均匀展墙光], [单件居中或不对称挂墙], [中性暖灰／自然色]
```

四段式：材质 → 光线 → 构图 → 色彩后期，总共不超过 8 个形容词。图片里不要生成展签文字，展签由 HTML 排版。

## 中文说明

- 作品边缘清晰，保留真实画幅，不用圆角、玻璃反射或界面框。
- 画面外留足暖灰墙面；作品的颜色可以丰富，环境颜色保持克制。

## 变体

**展览主视觉**
```
[展览主题／装置材质], [柔和顶光], [全幅单件／偏心], [中性墙色／自然色]
```

**摄影作品**
```
[摄影主体／银盐质感], [原始场景光], [单一视觉中心／留白], [自然色彩／不过度锐化]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
UI 卡片、按钮、文字、水印、画框堆叠、彩色氛围光、过曝、塑料质感
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 主视觉 16:10；作品按原始比例 |
| 光线 | 均匀、柔和平顶光 |
| 色温 | 中性或略暖 |
| 后期 | 保留材质，不做高饱和 HDR |
| 禁忌 | 文字、Logo、界面元素、厚投影 |
