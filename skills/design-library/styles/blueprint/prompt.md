# Blueprint｜工程蓝图 · 生图 Prompt 模板

## 主模板（可直接用）

```
[白线描绘的剖面图或爆炸结构图], [无光源变化 / 平涂 / 无景深], [正交网格上的 45deg 引出线与等距标注], [蓝晒蓝 #0B3D91 + 图纸白 #E8F1FF + 标注黄 #FFD36A / 1px 硬边 / 20px 网格]
```

四段式：主体 → 光线 → 构图 → 色彩后期。只描述物件、位置与色值，不描述情绪；总形容词不超过 8 个。画面里不要生成文字，图块编号、尺寸标注与按钮由 HTML/CSS 排版。

## 中文说明

- 主体只取技术图语汇：剖面图、平面图、爆炸图、流程图、正交投影的机件轮廓；不要真人、动物、家具实物、城市街景与 3D 拟物。
- 背景 `#0B3D91` 打底，叠 20px 间距 `rgba(232,241,255,0.12)` 双向白线网格；网格是制图坐标，不是发光点阵，也不铺到画面外。
- 线条用 `#E8F1FF`，次级线用 `#9EC1FF`；标注黄 `#FFD36A` 只给一处尺寸标记或关键数字，面积 ≤5%，不铺底。不要引入 Mid Blue、Callout Orange、Revision Violet 或任何紫蓝渐变。
- 所有边缘刀切：1px 线框、0px 圆角、零模糊、零投影；辅助关系用 dash 4px / gap 4px 的虚线，不拿虚线当纹理。
- 构图对齐 20px 网格，允许正交线与 45° 引出线，不出现自由角度曲线；角落可放一处细十字准星，面积 ≤1%。
- 线稿要像还没施工的图纸：结构清楚、留白规整、信息可定位；不要破损纸纹、褪色滤镜、景深或年代做旧。

## 变体

**结构爆炸图**
```
[白线爆炸机件轮廓 + 正交投影], [无光源 / 平涂 / 无阴影], [45deg 引出线连接各部件 / 部件沿 20px 网格等距排列], [蓝晒蓝 #0B3D91 + 图纸白 #E8F1FF / 1px 线框 / 一处标注黄 #FFD36A]
```

**章节分隔图**
```
[一条 1px 图纸白实线 + 两条虚线辅助线], [无光源变化 / 硬边], [水平横贯画面 / 上下留蓝底坐标网格], [#0B3D91 + #E8F1FF + #9EC1FF / 零模糊 / 标注黄只给一个数字]
```

**氛围背景**
```
[20px 双向白线网格 + 一处细十字准星], [蓝底平涂 / 无柔光], [网格铺满 / 中部保留纯蓝图面给正文], [#0B3D91 + rgba(232,241,255,0.12) / 无发光无景深]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
文字、Logo、水印、真实建筑事务所标识、城市地铁线路图、硬件品牌图纸、霓虹发光、科幻 HUD、数据大屏青光、黑底、纯白画布、暖色背景、紫蓝渐变、紫粉渐变、玻璃质感、模糊、软阴影、圆角、胶囊、有机曲线、彩色摄影、3D 拟物、景深、HDR、破损纸纹、密集点阵、装饰虚线、大面积标注黄
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 主视觉 4:3 或 16:9；章节图 21:9；氛围背景 16:9 |
| 光线 | 无真实光源；线框上边缘略亮于下边缘，固定左上方向，不投影 |
| 色温 | 蓝晒蓝打底；图纸白负责结构，标注黄只给关键数字，三色不调和 |
| 后期 | 20px 网格硬边平铺；正交线与 45° 引出线；零模糊、零景深、零做旧滤镜 |
| 禁忌 | 文字、商标、黑底、纯白、紫蓝渐变、发光、圆角、软影、彩色摄影、第四种强调色 |
