# Developer Docs · 生图 Prompt 模板

## 主模板

```text
浅色开发者文档工作区, 清楚的左侧导航与代码块, 柔和自然光,
长文档阅读布局, 单色青绿强调, 高可读无衬线排版, 代码与说明并列
```

## 中文说明

用成熟的软件文档工作区表达技术可信度。代码块必须像真实内容区，不使用满屏终端、绿色字符雨或伪造命令。

## 负向词

```text
terminal costume, code rain, neon green, cyberpunk, fake API output,
purple gradient, floating code snippets, unreadable small text
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 16:10 |
| 光线 | 柔和自然光 |
| 色温 | 中性略暖 |
| 后期 | 清楚、低对比背景、高文字可读性 |
| 禁忌 | 全屏终端、代码雨、霓虹 |
