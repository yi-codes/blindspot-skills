# Newsprint Grid｜新闻纸网格 · 生图 Prompt 模板

## 主模板（可直接用）

```
[新闻主体／纪实材质], [现场自然光], [单一事件中心／横向], [自然色彩／轻微颗粒]
```

四段式，总共不超过 8 个形容词。新闻图片应提供事实现场，不生成文字、标题或报纸版面。

## 中文说明

- 图像优先纪实摄影和现场细节，不做营销插画。
- 同一组新闻图保持相近色温与颗粒，不混用 3D、油画和卡通。

## 变体

**封面故事**
```
[封面事件／纪实摄影], [现场光], [横向全景／主体明确], [自然色／轻颗粒]
```

**人物报道**
```
[人物与工作环境], [窗侧自然光], [环境肖像／视线留白], [低饱和／真实肤色]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
报纸文字、虚构标题、水印、广告海报、过度 HDR、廉价 stock photo、3D 渲染
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 封面 16:9；次故事 4:3 |
| 光线 | 现场自然光 |
| 色温 | 按现场，不统一成暖橙 |
| 后期 | 轻颗粒、自然对比 |
| 禁忌 | 文字、Logo、摆拍营销感 |
