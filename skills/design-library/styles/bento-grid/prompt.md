# Bento Grid｜便当格 · 生图 Prompt 模板

## 主模板（可直接用）

```
[浅灰画布上的圆角模块拼贴], [顶部柔光 / 无硬影], [大小不等的格子紧密排布 / 主格占半屏], [浅灰白卡 + 一个靛蓝主格]
```

四段式：模块主体 → 光线底色 → 构图 → 色彩后期。只描述格子的形状、面积和位置，不描述情绪；总形容词不超过 8 个。画面里不要生成文字，标题由 HTML 排版。

## 中文说明

- 画面是一组大小不等的矩形圆角模块，像便当盒一样紧密拼满，格距一致，不出现空洞。
- 一个主格占画面约一半面积并填靛蓝，其余为浅灰白卡；彩色格不超过两个，琥珀只做小面积数字或标记。
- 所有模块圆角半径一致，无厚边框、无硬阴影、无玻璃质感；层级靠面积和底色差。
- 背景是浅灰不是纯白；每格内容抽象为一个数字、一个几何图标或一块裁切图片。

## 变体

**产品功能墙**
```
[浅灰底圆角模块拼贴], [均匀顶光], [一个大格在左 + 五个小格填充右侧], [白卡为主 / 一个靛蓝主格 / 一个琥珀数字]
```

**发布会规格格**
```
[圆角矩形矩阵], [无影平光], [中心大格展示主数字 / 周围小格环绕], [浅灰白卡 / 靛蓝强调 / 等宽数字感]
```

**单格图标或空态**
```
[一个圆角方块], [无光 / 纯色底], [居中 / 网格对齐], [靛蓝或琥珀单色 / 1.75px 描边]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
文字、Logo、水印、渐变、玻璃质感、金属光泽、硬投影、厚边框、圆角不一致、格子空洞、粉彩色、杂乱纹理、拟物图标
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 功能墙 16:10 或 4:3；单格图标 1:1 |
| 光线 | 均匀顶光或无光，边缘清晰不带羽化 |
| 色温 | 中性偏冷，浅灰画布 |
| 后期 | 实色印刷感，极淡投影，不做高饱和 HDR |
| 禁忌 | 文字、Logo、界面元素、渐变、硬阴影、混用圆角 |
