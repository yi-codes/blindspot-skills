# Vaporwave｜蒸汽波 · 生图 Prompt 模板

## 主模板（可直接用）

```
[复古主体：古典石膏胸像 / 老式电视机 / 棕榈树 / 铬制几何体], [粉青落日 + 顶部柔光], [透视网格地平线 + 居中偏下视觉重心], [粉青霓虹 + 轻微 CRT 扫描线 + 淡色差]
```

四段式：主体 → 光线 → 构图 → 色彩后期。只描述物件、位置与光色，不描述情绪；总形容词不超过 8 个。画面里不要生成文字，标题由 HTML 排版。

## 中文说明

- 主体必须是 1980–90 年代可辨认的旧物或古典石膏像，一件占画面 40% 以上，其余作次级节奏；不要出现真人正脸。
- 粉 #FF71CE 与青 #01CDFE 必须同时出现，落日放画面上部或灭点处；薄荷与淡黄只作小面积点缀。
- 透视网格退向单一灭点，占画面下部约三分之一，向上淡出；线宽 1px 观感，不做粗网格。
- 整体轻微褪色、像旧显示器：低饱和一档、可见细扫描线、边缘 2px 青粉错位；不要高饱和 HDR。
- 禁止任何品牌商标、日文假名招牌、授权字体与水印；年代感靠物件与光色，不靠文字。

## 变体

**专辑封面 / 演出主视觉**
```
[居中石膏胸像 + 条纹落日], [粉青落日 / 顶部柔光], [网格地平线 / 胸像占中心 50%], [霓虹粉青 / 淡扫描线 / 2px 色差]
```

**产品 / 潮流周边海报**
```
[老式消费电子或铬制几何体], [单侧霓虹粉光 / 青色环境光], [居中偏下 / 上方大面积深紫留白], [粉青双霓虹 / 实色硬边 / 无投影]
```

**图标与空态插画**
```
[单一旧物轮廓], [无光 / 深紫底], [居中 / 24px 网格对齐], [青或粉单色 / 1.5px 描边]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
文字、Logo、水印、日文招牌、真人正脸、紫到蓝渐变、紫到粉渐变、渐变文字、现代极简、纯白背景、企业风、高饱和 HDR、居中发光、粗网格、杂乱纹理
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 主视觉 4:3 或 3:4；封面 1:1；图标 1:1 |
| 光线 | 顶部落日柔光 + 粉青双向霓虹，主体边缘有轻微辉光 |
| 色温 | 深紫暗场为底，粉青霓虹提亮，整体偏冷但带暖粉点缀 |
| 后期 | 褪色一档、细扫描线、2px 青粉色差，保留 CRT 观感 |
| 禁忌 | 文字、商标、紫蓝/紫粉渐变、渐变字、纯白背景、现代极简、居中发光 |
