# 新拟态｜Neumorphism · 生图 Prompt 模板

## 主模板（可直接用）

```
[同色哑光塑料控件], [top-left 单一柔和光，双向投影], [控件从底面浮起或陷入], [单色暖灰底，无色块无描边]
```

四段式：材质 → 光线 → 构图 → 色彩后期。每段最多两个词，总形容词不超过 8 个。画面里不要生成文字，标题由 HTML 排版。

## 中文说明

- 控件与底同色，靠左上高光 + 右下暗影塑造「浮起」，靠反向 inset 塑造「陷入」；不靠描边也不靠色块。
- 光源固定左上，画面里只能指认出一个方向的光；四处都有高光就是破功。
- 底色是温暖的中性灰（#E7E5E4 一带），不是纯白也不是纯黑；青与绿只作主操作和状态，占比不超过 10%。
- 圆角偏大、胶囊按钮、无锐角；材质是柔软哑光塑料，不是玻璃、金属或发光体。

## 变体

**硬件控制面板**
```
[胶囊旋钮与滑杆], [左上柔光双向投影], [凹槽面板内嵌控件], [单色暖灰，青色主操作]
```

**状态卡片**
```
[圆角矩形卡片浮起], [top-left 柔光，右下长阴影], [卡片与凹槽并列], [暖灰同色系，绿色状态点]
```

**空态与图标**
```
[柔软圆角凹槽], [左上高光一条], [居中留白], [暖灰底，青色线性图标]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
文字、Logo、渐变、玻璃质感、金属光泽、霓虹发光、纯白背景、纯黑描边、彩色色块、硬边框、四处高光、锐角、投影贴图
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 控制面板 4:3；状态卡片 3:2；图标与空态 1:1 |
| 光线 | top-left 单一柔和光源；凸起右下长阴影 + 左上高光，凹陷反之 |
| 色温 | 暖中性灰底（#E7E5E4），中性偏暖色温，无霓虹色偏 |
| 后期 | 哑光塑料质感，柔和不糊；阴影有明确方向与偏移，不做居中发光 |
| 禁忌 | 文字、Logo、渐变、玻璃、金属、发光、纯白底、硬描边、多色块 |
