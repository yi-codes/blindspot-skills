# Bauhaus Grid｜包豪斯几何 · 生图 Prompt 模板

## 主模板（可直接用）

```
[圆/方/三角主体], [暖纸白底 + 单侧硬光], [不对称网格 / 大面积留白], [红蓝黄三原色实块 / 无渐变]
```

四段式：几何主体 → 光线底色 → 构图 → 色彩后期。只描述形状、面积和位置，不描述情绪；总形容词不超过 8 个。画面里不要生成文字，标题由 HTML 排版。

## 中文说明

- 圆、方、三角只出现一到两个，其中一个占画面 40% 以上面积，其余作为次级节奏。
- 色块边缘清晰无羽化；圆=蓝、方=红、三角=黄是默认配对，但同屏不超过三种彩色。
- 背景是暖纸白，不是纯白；允许可见纸张颗粒，不允许渐变、玻璃、金属或发光。

## 变体

**展览主视觉**
```
[一个大圆 + 一个矩形], [暖纸白 / 平顶硬光], [左侧大形压右侧窄文字带], [红与蓝 / 直角 / 无阴影]
```

**产品/建筑海报**
```
[三角与矩形组合], [纸白背景 / 单一斜向对角线], [居中偏下的视觉重心 / 上方留白], [黄与黑 / 实色印刷]
```

**图标与空态插画**
```
[单一几何形状], [无光 / 纯色底], [居中 / 24px 网格对齐], [蓝或红单色 / 2px 描边]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
文字、Logo、水印、渐变、玻璃质感、金属光泽、投影、柔焦、粉彩色、有机曲线、拟物图标、杂乱纹理
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 主视觉 4:3 或 3:4；图标 1:1 |
| 光线 | 平顶硬光或无光，形状边缘不带羽化 |
| 色温 | 暖纸白底，中性色温 |
| 后期 | 实色印刷感，保留轻微纸张颗粒，不做高饱和 HDR |
| 禁忌 | 文字、Logo、界面元素、渐变、投影、圆角卡片 |
