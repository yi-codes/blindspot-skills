# Sketch Notes｜手绘笔记 · 生图 Prompt 模板

## 主模板（可直接用）

```
[解释主体／钢笔线稿], [纸面平光], [手绘图解／局部批注], [暖纸与墨色／一点蓝]
```

四段式，总共不超过 8 个形容词。不要生成可读文字；标签、步骤和解释由真实排版层提供。

## 中文说明

- 图形应该帮助理解结构、因果或步骤，不只是装饰涂鸦。
- 线条允许轻微抖动和双线，主体轮廓必须清楚；不要随机旋转整幅图。

## 变体

**概念图解**
```
[概念对象／双线钢笔], [均匀纸面光], [分步箭头／留白], [墨线／蓝色重点]
```

**工作坊插图**
```
[人物与材料／铅笔质感], [自然平光], [动作过程／边注位置], [暖纸／局部黄色标记]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
可读文字、伪文字、Logo、写实油画、3D 渲染、复杂背景、随机乱线、低对比黄字
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 图解 3:2；卡片 4:3 |
| 光线 | 平光，无强烈投影 |
| 色温 | 暖纸、中性墨线 |
| 后期 | 轻纸纹、固定线宽 |
| 禁忌 | 伪文字、过度抖动、立体高光 |
