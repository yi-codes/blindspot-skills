# Frutiger Aero｜晴空拟物 · 生图 Prompt 模板

## 主模板（可直接用）

```
[玻璃或水做的主物件：气泡 / 水滴 / 磨砂玻璃球 / 晴空窗], [天蓝到草绿的通透渐变 + 左上柔光], [居中偏上、大面积晴空留白 + 小物件浮动], [高光条 + 轻微景深 + 干净不过曝]
```

四段式：主体 → 光线 → 构图 → 色彩后期。只描述物件、位置与光色，不描述情绪；总形容词不超过 8 个。画面里不要生成文字，标题由 HTML 排版。

## 中文说明

- 主体必须是玻璃、水或晴空类可辨认的物件，一件占画面 30%–50%，其余作气泡与光斑的次级节奏；不要出现真人正脸。
- 天蓝 `#EAF6FF` 到草绿 `#7ED957` 的渐变必须出现，光从左上打入；青柠与日光黄只作小面积点缀。
- 玻璃要有明确的高光条与 1px 浅边，像能被触摸的塑料或水；不要硬黑影、不要粗描边。
- 气泡与光斑缓慢浮动的观感：轻微景深、通透不过曝；不要高对比 HDR，也不要破损纹理与纸纹。
- 禁止任何品牌商标、Windows / iOS 徽标、热带鱼壁纸、Frutiger 等商业字体水印；年代感靠玻璃质感与光色，不靠文字与 logo。

## 变体

**产品 / 品牌主视觉**
```
[磨砂玻璃球或水滴包裹的物件], [天蓝渐变 / 左上柔光 + 顶部高光条], [居中偏上 / 上方大面积晴空留白], [玻璃通透 / 青绿渐变 / 无硬影]
```

**图标与空态插画**
```
[单一玻璃或水滴轮廓], [天蓝底 / 无强光], [居中 / 24px 网格对齐], [深青 #0288D1 单色 / 1.6px 描边]
```

**氛围背景**
```
[气泡与水滴群], [天蓝到草绿渐变 / 左上柔光], [散布 / 20%–60% 面积], [白色高光 / 轻微景深 / 无文字]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
文字、Logo、水印、Windows 徽标、iOS 图标、热带鱼照片、真人正脸、硬偏移黑影、粗黑描边、破损纸纹、像素字、高对比 HDR、纯白背景、扁平极简、紫蓝渐变、紫粉渐变
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 主视觉 16:9 或 4:3；图标 1:1；氛围背景 16:9 |
| 光线 | 左上柔光 + 玻璃顶部高光条，主体边缘通透、不过曝 |
| 色温 | 天蓝到草绿渐变打底，青柠与日光黄小点缀，整体明亮偏冷 |
| 后期 | 轻微景深与通透感，气泡边缘保留白色高光，不要 HDR 与粗颗粒 |
| 禁忌 | 文字、商标、硬黑影、粗描边、纸纹、扁平极简、纯白背景 |
