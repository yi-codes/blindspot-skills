# Liquid Glass · 生图 Prompt 模板

## 主模板

```text
磨砂玻璃工作面板, 近中性冷灰背景, 柔和散射光, 轻微环境折射,
平行视角, 留出真实界面文字区, 低饱和冷蓝单强调色, 克制高光, 无霓虹
```

## 中文说明

玻璃必须偏实，能透出环境但不能影响阅读。画面只保留一个冷蓝信号。避免彩虹光、发光球、夸张景深和透明塑料感。

## 负向词

```text
rainbow gradient, neon glow, purple blue, oversaturated, transparent plastic,
floating glass shards, heavy bokeh, fake UI text
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 16:10 |
| 光线 | 柔和侧上方散射光 |
| 色温 | 偏冷中性 |
| 后期 | 低对比、克制高光 |
| 禁忌 | 多色光斑、强发光、过度透明 |
