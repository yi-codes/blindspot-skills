# Adaptive Companion · 生图 Prompt 模板

## 主模板

```text
跨设备陪伴型工作界面, 手机与平板并列, 柔和中性表面, 大触控目标,
渐进信息布局, 拇指可达主操作, 低饱和蓝绿强调, 安静自然的日常环境
```

## 中文说明

重点是同一任务在不同设备上的连贯关系，不是把桌面后台缩小。画面应体现触控、单手操作和渐进披露，不堆装饰性插图。

## 负向词

```text
tiny mobile dashboard,KPI card wall, neon glow, purple gradient, fictional mascot,
desktop table squeezed into phone, floating glass cards
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 4:3 或 16:10 |
| 光线 | 室内柔和自然光 |
| 色温 | 中性 |
| 后期 | 低饱和、清楚触控层级 |
| 禁忌 | 小屏宽表、霓虹、卡通吉祥物 |
