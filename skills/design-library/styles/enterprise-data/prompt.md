# Enterprise Data · 生图 Prompt 模板

## 主模板

```text
组织化业务数据工作台, 密集表格与清晰筛选, 中性冷灰表面,
均匀顶部工作光, 稳定行列对齐, 深绿主操作, 可审计的 B 端管理界面
```

## 中文说明

画面重点是数据关系、操作范围和审计路径。避免 KPI 卡片墙和装饰性图表。表格必须像真实工具，而不是营销截图。

## 负向词

```text
KPI card wall, decorative donut charts, neon data dashboard, glass cards,
purple gradient, unreadable tiny tables, floating widgets
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 16:9 |
| 光线 | 顶部均匀工作光 |
| 色温 | 冷中性 |
| 后期 | 清楚、低饱和、行列可读 |
| 禁忌 | KPI 卡片墙、装饰图表、霓虹 |
