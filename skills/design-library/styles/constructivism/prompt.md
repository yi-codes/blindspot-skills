# Constructivism｜构成主义海报 · 生图 Prompt 模板

## 主模板（可直接用）

```
[硬边黑白摄影裁切 / 直角红楔与墨色直条], [左上单一硬光 / 零模糊 / 无渐变], [沿 -12deg 对角线相撞的非对称构图 / 右侧留出纯纸色文字区], [泛黄纸 #F2E8D5 + 革命红 #CC0000 + 暖墨 #1A1A1A 三色平涂 / 4px 硬边 / 粗网点只占一角]
```

四段式：主体 → 光线 → 构图 → 色彩后期。只描述物件、位置与色值，不描述情绪；总形容词不超过 8 个。画面里不要生成文字，标题与按钮由 HTML 排版。

## 中文说明

- 主体必须是可辨认的实物裁切与硬边几何：黑白人物或建筑照片的矩形抠图、斜切红楔、墨色直条至少出现两类；不要真人正脸特写、动物、家具实物、3D 拟物。
- 背景纸色 `#F2E8D5` 打底，红色 `#CC0000` 只做一处主楔，暖墨 `#1A1A1A` 做最粗的斜条与边框。三色封顶，不出现第四种颜色；金星色与棕色不迁移。
- 所有边缘刀切，4px 墨线勾边，硬影写 `4px 4px 0` 零模糊；没有玻璃高光、发光、柔光或背景渐变。
- 红楔用 -12° 斜切，`clip-path` 多边形；分隔条 -2° 倾斜。构图左对齐、非对称，允许色块溢出画面边缘，不做居中对称。
- 粗网点用 `radial-gradient(circle, #1A1A1A 1px, transparent 1.2px) 0 0 / 4px 4px`，只占图片块或画面一角，面积 ≤20%，不压在预留给文字的纯纸色区域。
- 摄影素材做 `grayscale(1) contrast(1.15)` 硬边裁切，不做双色调、不做景深；年代感来自构图与三色关系，不来自破损纸纹滤镜。
- 禁止任何历史海报构图、政治标识、红星、锤镰、真实品牌商标、名人脸；字标只写排字规则，字体也不写进画面。

## 变体

**活动主视觉**
```
[黑白建筑照片的矩形抠图 + 斜切红楔], [左上硬光 / 零模糊 / 平涂], [对角线主轴 / 文字区留在左下 / 色块溢出右边], [纸色 #F2E8D5 + 红 #CC0000 + 墨 #1A1A1A / 4px 墨线 / 一角粗网点]
```

**章节分隔图**
```
[一条 4px 墨色直条 + 两个直角红黑块], [无光源变化 / 硬边 / 无渐变], [-2° 倾斜横贯画面 / 上下留纯纸色], [三色封顶 / 零模糊 / 图案面积 ≤20%]
```

**氛围背景**
```
[粗网点 + 一处 -12° 红楔], [纸色平涂 / 无柔光], [网点只在右下角 / 中部纯纸色留给正文], [#F2E8D5 + #CC0000 + #1A1A1A / 无模糊无景深]
```

## 负向词

见 `../../prompts/negative.md`，额外加入：

```
文字、Logo、水印、历史海报、政治标识、红星、锤镰、名人肖像、真实品牌、柔和阴影、居中发光、渐变、玻璃质感、圆角、有机曲线、波浪线、插画、3D 拟物、景深、HDR、破损纸纹、像素字、居中对称、三等分排版、第四种颜色
```

## 参数建议

| 项 | 建议 |
|---|---|
| 画幅 | 主视觉 4:3 或 16:9；章节图 21:9；氛围背景 16:9 |
| 光线 | 左上单一硬光，投影固定向右下 4px 4px 0，无柔光、无环境光、无发光 |
| 色温 | 泛黄印刷纸打底；红只做一处主楔，墨负责边框与粗条，三色不调和 |
| 后期 | 平涂无渐变、无景深、无颗粒滤镜；粗网点只在图片块或一角，边缘保持刀切 |
| 禁忌 | 文字、商标、政治符号、圆角、软影、渐变、对称三等分、第四色 |
