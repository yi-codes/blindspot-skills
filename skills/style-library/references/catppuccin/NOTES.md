# Catppuccin

## 来源

- 仓库：`catppuccin/palette`（官方色板仓库，带版本号）
- 实际读取：`palette.json`（4 个 flavor × 26 色，每色带 `order` 字段）
- 抓取：2026-11-16

**这一份和前面所有样本都不同：它是调色板，不是设计语言。**

它回答"用什么颜色"，不回答"怎么排版"。没有字号、没有圆角、没有间距、没有组件规范。所以从它做风格，**颜色是可复现的，形状是补的**——这个区别写在了 `soft-pastel/DESIGN.md` 的第一节。

## 取（吸收了什么，落到哪）

### 1. 两套 flavor 的完整 26 色

Latte（浅）+ Mocha（深），每色原样搬进 `--sp-*`。没用 Frappé / Macchiato。

→ `soft-pastel/tokens.css`。

### 2. 三层的明度顺序

`crust < mantle < base`，而且 **mantle 比 base 暗**——卡片是"陷进去"的，不是浮起来的。这和我之前做的 `quiet-dark`（卡片比底亮）相反。

→ 落到 canvas / surface / sunken 三档。两套都遵守这个方向。

### 3. 14 个 accent 全部压在同一明度带

这是它能"柔和"而不"花"的原因：色相差异很大，明度差异很小。

→ 落成一条规则："同一屏最多三个色相"。

### 4. `order` 字段

0-25 的序号，用于"按什么顺序取色"。图表取色可以照着跳着取。

→ 写进了 Known Gaps 的建议（按 order 跳着取，不要取相邻色）。

## 弃（明确不吸收，为什么）

- **Frappé / Macchiato 两个 flavor。** 中间调。加进来会让"该选哪个"变成三个选项，而它们的差异小到不值得。只留最亮和最暗两头。
- **把 14 个 accent 当"14 个可用颜色"来用。** 这是这个风格最容易犯的错，我算过对比度才发现：**Latte 里只有 mauve(4.79) 和 red(4.80) 能当文字色**，其余 12 个全部低于 4.5:1，只能做填充。这一步配色方案不会告诉你。
- **用官方色之外的新色。** 只破例一次：Latte 的 `surface-raised` 借了纯白（#FFFFFF），因为 Latte 里没有比 base 更亮的色，而弹层必须比底亮。已在 tokens.css 里就地注明。
- **"柔和 = 全圆角"的理解。** 三档圆角（8 / 12 / full）而不是全部 pill。

## 待观察

- **卡片必须补 1px 描边。** 这是做出来才发现的：Latte 的 mantle 对 base 只有 **1.04:1**，纯靠明度分不出卡片。所以"零边框零阴影"在浅色版执行不了。这个教训写进了 `principles.md` §9 和 `soft-pastel/DESIGN.md`。
- **降级为可访问性弱项。** 12/14 个色不能做文字 + 紫绿搭配是红绿色盲高危组合。已写进 Known Gaps 并建议改用 `quiet-dark` / `civic`。
- 图表配色方案没定（14 选 5）。
- 移动端、空状态、加载态都没做。
- 组件的形状规则（圆角、内边距、hover 效果）全部是本库补的，没有外部依据。这是这份文档里"最软"的部分。
