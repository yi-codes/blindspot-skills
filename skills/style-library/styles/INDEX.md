# 风格索引

> 这个文件是**脚本生成的**，不要手改。
> 改风格的选择条件，去改那个风格 `DESIGN.md` 的 front matter，然后跑：
>
> ```bash
> python3 scripts/build-index.py
> ```

当前 **8** 个风格。

## 决定表

先定**这篇东西要让读者确认什么**，再在那一组里挑。

| 读者要确认的 | 职守 | 风格 |
|---|---|---|
| 「这人靠谱 / 这东西有品」 | 讲故事 | `editorial-serif`、`neobrutalist` |
| 「这东西好用 / 这公司专业」 | 讲专业 | `civic`、`swiss-grid` |
| 「这人技术过硬」 | 讲技术 | `academic`、`terminal-mono` |
| 「这是给专业人做的」 | 讲工具 | `quiet-dark`、`soft-pastel` |

## 交叉表（职守 × 密度）

定了职守还挑不出来时看这张。**密度是「这一屏要塞多少东西」，不是「留白多少」** ——
紧 = 信息密度优先，松 = 阅读节奏优先。

| 职守 | 紧 | 中 | 松 |
|---|---|---|---|
| 讲故事 | — | `neobrutalist` | `editorial-serif` |
| 讲专业 | — | `civic`、`swiss-grid` | — |
| 讲技术 | `terminal-mono` | — | `academic` |
| 讲工具 | `quiet-dark` | — | `soft-pastel` |

有 1 个格子塞了不止一个风格 —— 那些格子还得往下看「明暗」，或者干脆各写各的场景。

## 用法速查

```html
<!-- 引入某个风格 -->
<link rel="stylesheet" href="styles/<slug>/tokens.css">
<div class="ds-<slug>"> … </div>
```

变量前缀见每个风格 `tokens.css` 顶部的注释（`--ed-*` / `--sw-*` …）。

## 排他说明

`avoid` 里列的不是「不推荐」，是「**别用**」。
一个风格用在它 avoid 的场景里，出来的东西一定像模板 —— 因为它没为那个场景做过约束。

全都排除了，说明这里该开一个新风格（见 `principles.md` §8），而不是硬套。
