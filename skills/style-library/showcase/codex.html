修复 auth 测试的偶发失败

auth 的测试在 CI 上偶发失败，大概 30% 的概率。帮我看下原因，能修就修。
Codex

先跑 20 次复现，看失败是不是集中在同一个用例上。

$pnpm vitest run src/auth --repeat 20 42.6s
✓ 18 passed ✓ suite src/auth/refresh.spec.ts ✗ 2 failed › refreshes an expired token AssertionError: expected 401 to be 200 at src/auth/refresh.spec.ts:34:20

两次失败都在同一个用例上，而且都在 token 刚刚过期的边界。 去看了 refresh.ts 的判断：边界用的是 > 而不是 >=， 所以过期时刻那一毫秒被当成"还没过期"，签名校验就失败了。

src/auth/refresh.ts +1−1
const now = Date.now();
− if (now > expiresAt) return null;
+ if (now >= expiresAt) return null;

改完重跑 20 次，全绿。顺手在 refresh.spec.ts 补了一个卡边界的用例， 免得以后有人把 >= 又改回去。
