手感是可以写死的

“拖起来丝滑”不是形容词。它是 ω=7.6、ζ=0.82、1/240 秒子步进 这三个数。 下面三块都能上手：拖、悬停、按。右边那块用 CSS 过渡实现，你可以直接看出两者的差别。

① 拖它

七张盒面 / 半径 340px / 透视 1400px

按住左右拖，松手会先滑一段再吸附到最近一格。拖拽中弹簧更硬（ω=18）， 松手后变软（ω=12），这样跟手和收尾是两种手感。

② 悬停它

倾角上限 12° / 透视 800px / 高光上限 0.34

高光跟着指针走，阴影跟着倾角走。注意卡片上那层数字（+30px）比卡面浮得高， 所以倾斜时它移动得更多——这个视差就是“有厚度”的直接证据。
