# 风格词表

生图时最卡的一步不是"想不出画面"，是**知道自己想要什么感觉，但说不出对应的词**。
这份表按维度拆开，每个维度挑 1-2 个词组合，出来的风格才是可控的。

用法：`[光线] + [材质] + [构图] + [色彩后期]`，四段式拼装，别一次堆十个形容词。

---

## 1. 光线

决定画面情绪的第一变量，比主体更重要。

| 中文感觉 | 英文词 | 说明 |
|---|---|---|
| 单侧窗光 | `single window light` | 最耐看的光，明暗交界线清楚 |
| 大面积柔光 | `large softbox` `soft diffused light` | 均匀、干净，产品图首选 |
| 硬光 | `hard light` `direct sun` | 影子边界锐利，秩序感强 |
| 逆光 | `backlit` `rim light` | 主体轮廓发光，适合人物和植物 |
| 侧逆光 | `side-back light` | 层次最丰富，静物神器 |
| 高调 | `high key` | 亮部为主，几乎没黑，干净 |
| 低调 | `low key` | 暗部为主，只留一束光，戏剧感 |
| 黄金时刻 | `golden hour` | 暖、低角度、长影子 |
| 蓝调时刻 | `blue hour` | 冷、均匀、安静 |
| 阴天散射 | `overcast` | 无方向，反差低，纪实感 |
| 屏幕光 | `screen glow` | 冷、从下往上、科技感 |

## 3. 构图与镜头

| 中文感觉 | 英文词 | 用在哪 |
|---|---|---|
| 平铺俯拍 | `flat lay` `top-down` | 静物、工具、桌面 |
| 完全水平 | `camera perfectly level` `eye-level` | 建筑感、产品正面 |
| 微距 | `macro shot` `extreme close-up` | 质感特写、屏幕 |
| 浅景深 | `shallow depth of field` | 突出主体，弱化背景 |
| 全清晰 | `sharp focus throughout` | 产品、建筑、网格风 |
| 大量留白 | `generous negative space` | 要放文字的图必须加 |
| 居中对称 | `centered symmetrical` | 秩序、正式、仪式感 |
| 三分偏置 | `rule of thirds` `off-center` | 自然、有呼吸 |
| 广角压迫 | `wide angle` `24mm` | 空间感、环境叙事 |
| 长焦压缩 | `telephoto` `85mm` `compressed perspective` | 人像、背景虚化 |
| 微距景深合成 | `focus stacking` | 极清晰的产品细节 |

## 4. 色彩与后期

| 中文感觉 | 英文词 | 说明 |
|---|---|---|
| 低饱和 | `muted colors` `desaturated` | 高级感的基础 |
| 大地色 | `earth tones` `bone white` `warm grey` | 编辑感核心 |
| 单色系 | `monochromatic` | 只用一个色相的不同明度 |
| 一个强调色 | `single accent color` | 比多色高级得多 |
| 高对比黑白 | `high contrast black and white` | 力量、纪实 |
| 胶片模拟 | `film emulation` `Portra 400` `Ektar` | 暖肤色、柔和过渡 |
| 冷调科技 | `cool color grade` `teal and amber` | 影视常用的互补配色 |
| 柔和过渡 | `soft rolloff` `gentle gradient` | 不生硬，专业感 |
| 抬黑位 | `lifted blacks` `milky blacks` | 胶片感，不闷 |
| 锐利通透 | `crisp` `clean` `no grain` | 商业产品风 |

## 6. 情绪词

这些东西模型能"感觉到"，但对画面控制力弱，只用来定调，不要指望它决定构图。

`quiet` `considered` `moody` `clinical` `nostalgic` `tense` `warm` `detached` `precise` `raw` `serene` `restrained`

---

## 拼装示例

**要一张博客头图，安静、纸感、能放标题**

```
editorial still life, folded linen cloth, single window light, generous negative space
on the right, muted earth tones with one rust accent, analog film grain
```

四段：材质 → 光线 → 构图 → 色彩后期。干净，可控，不靠堆词。

**要一张技术文章配图，暗、有屏幕感**

```
macro shot of a dark terminal screen, screen glow as only light source,
shallow depth of field, soft green monospace characters, low key
```

---

## 一条纪律

**四段式，每段最多两个词。** 超过八个形容词，模型会开始丢掉后面的。
如果效果不对，先删词，再加词 —— 大概率是互相冲突了（比如 `high key` 配 `low key`、
`sharp focus throughout` 配 `shallow depth of field`）。
